Case study

Platonic Beauty: online booking for a men's and women's salon

The brief. A US salon for men and women wanted customers to book without calling, to be found in local search, and to use the site in their own language.

What I built

  • Real-time booking. Free times by stylist and service, grouped by morning, afternoon and evening, with no double-booking.
  • Passwordless sign-in. A one-time code by text or email, with rate limits and hashed storage.
  • Local SEO. Editable titles and descriptions per page, hreflang, sitemap and structured data.
  • Four languages. English, Spanish, French and Persian, with right-to-left layout.
  • Companion mobile app. Flutter app on the same JSON API for services, booking, gallery and reviews.
  • Staff panel. Bookings, stylists' hours, price list, gallery and review moderation.

Under the hood

Python 3.12 · Django 5 · HTMX · Alpine.js · PostgreSQL · Celery and Redis · Docker and Nginx · Flutter · REST/JSON API
